# Linux

**状态：未实现。仅设计占位，技术路线待定。** 当前没有 Linux 程序、代理后端、构建入口或可用发布包。本目录不代表已支持 Linux，尚未选定发行版、内核要求或网络接管机制。

## 必须保留的约束

按指定进程接管流量，不使用 TUN、虚拟网卡或全局路由接管。后续独立设计 Linux 的网络接管、进程身份与后代跟踪、权限管理和生命周期清理，不将 Windows NetFilter SDK 或 ETW 作为 Linux 实现。

可参考现有 JSON 配置约定、中英消息目录和 SOCKS5 协议逻辑；实际代码复用范围需在确定原生技术路线后评估。不能通过增加空程序、无效果的后端或默默退回直连来宣称支持。

## 后续设计与验收要求

1. 确认可满足无隧道约束的原生接管方案，说明所需权限、内核功能、发行版和容器/命名空间边界。
2. 定义进程匹配、递归后代继承、父退出、PID 复用和首次联网时的归属判定行为。
3. 分别验证目标/非目标进程、TCP/UDP、IPv4/IPv6、局域网旁路、系统 DNS 行为和代理故障阻断。
4. 验证启动、权限拒绝、重复实例、停止与异常退出的资源清理；确保退出后不残留属于本工具的接管规则。
5. 提供 Linux 的构建、自动测试、真实系统验收和发布说明后，才能更改实现状态。

Windows 的验证结果不能作为 Linux 验收依据。当前可用版本见根目录 [使用说明](../../README.md)。

# macOS

**状态：未实现。仅设计占位，技术路线待定。** 当前没有 macOS 程序、代理后端、构建入口或可用发布包。本目录不代表已支持 macOS，也没有选定或验证签名、开发者账号、权限及分发方案。

## 必须保留的约束

按指定进程接管流量，不使用 TUN、虚拟网卡或全局路由接管。后续独立设计 macOS 的网络接管、进程身份与后代跟踪、权限管理和生命周期清理，不将 Windows NetFilter SDK 或 ETW 作为 macOS 实现。

可参考现有 JSON 配置约定、中英消息目录和 SOCKS5 协议逻辑；实际代码复用范围需在确定原生技术路线后评估。不能通过增加空程序、无效果的后端或默默退回直连来宣称支持。

## 后续设计与验收要求

1. 确认可满足无隧道约束的原生接管方案，以及其系统版本、授权、签名和分发要求；对账号要求给出实际验证结果。
2. 定义进程匹配、递归后代继承、父退出、进程身份复用和首次联网时的归属判定行为。
3. 分别验证目标/非目标进程、TCP/UDP、IPv4/IPv6、局域网旁路、系统 DNS 行为和代理故障阻断。
4. 验证启动、权限拒绝、重复实例、停止与异常退出的清理边界，并明确持续断网保护范围。
5. 提供 macOS 的构建、自动测试、真实系统验收和发布说明后，才能更改实现状态。

Windows 的验证结果不能作为 macOS 验收依据。当前可用版本见根目录 [使用说明](../../README.md)。
